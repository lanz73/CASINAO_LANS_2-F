ASSESSMENT 3.2: LINEAR DATA STRUCTURE
Last Name: CASINAO

Four separate Python programs:
1. 1_array_casinao.py
2. 2_stack_casinao.py
3. 3_queue_casinao.py
4. 4_linked_list_casinao.py

HOW TO RUN IN PYCHARM
1. Open PyCharm and create/open a Python project.
2. Place all four .py files in the project.
3. Open a file and click Run.
4. Press Enter when asked for a last name to use CASINAO.

Each program adds the letters one by one, displays the structure, and removes
letters until it becomes empty.

Removal:
- Array: removes from the front.
- Stack: removes the last item added (LIFO).
- Queue: removes the first item added (FIFO).
- Linked List: removes from the head.
